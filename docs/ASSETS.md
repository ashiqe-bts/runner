# Original asset sources

All models, clips, environment meshes, icons and audio are original procedural assets. No downloaded character packs, purchased models or sampled recordings are used.

## Native upgrade

- `tool/generate_couriers.dart` builds rounded, weighted human courier and officer meshes. A shared 20-joint rig articulates the spine, shoulders, elbows, hips, knees, ankles, cap and bag. Outfit colors preserve PIP/VOLT/NOVA IDs. Meshes contain about 4,500–4,900 vertices and 7,300–8,000 triangles per character.
- `tool/courier_animation.dart` generates ten distinct clips and two compatibility aliases. Running uses a two-bone leg calculation, opposite arm swing, ankle rotation, body lean and restrained bag movement. Animation clips are sampled into standard glTF tracks.
- `tool/generate_world.dart` builds shared city/station/tunnel geometry, distinct hazards, hover traffic, geometric signage and recognizable power-up meshes. Stars and paired coins have actual 2× marks.
- `tool/generate_wind.dart` synthesizes a seamless periodic wind spectrum. The original music and other effects remain generated by `tool/generate_assets.dart`.
- `lib/features/power_up_icon.dart` draws the corresponding UI symbols as vectors without external icon artwork.
- `art/models/` contains portable GLBs and the rig definition; `assets/native_models/` contains bundled models. `art/skyway/` contains RML, Luau, WGSL and binary meshes for the Rive gate. Its unsigned compiled artifact is `assets/rive/skyway.riv`; it is not used by the active renderer.

Regenerate from the repository root, using Dart from Flutter 3.47.2:

```sh
DART=/path/to/flutter-3.47.2/bin/dart
"$DART" run tool/generate_couriers.dart
"$DART" run tool/generate_world.dart
"$DART" run tool/generate_wind.dart
```

With Rive CLI 1.0.3 installed:

```sh
rive art/skyway --verify
rive inspect art/skyway --summary
rive art/skyway --screenshot --advance=1
rive art/skyway --once
cp art/skyway/build/skyway.riv assets/rive/skyway.riv
```

`--once` produces an unsigned scripted artifact. See [RIVE_GATE.md](RIVE_GATE.md) before attempting native playback or publishing. No Rive asset has been published to an account.

## Retained prototype

`tool/generate_assets.dart` creates the original six-joint robot models, eight clips, music and effects. `tool/generate_brand.dart` creates the existing robot application icon. These remain available for the browser prototype and are separate from the native human models. Running the original generator does not replace `assets/native_models/`.

Source GLBs are converted by the Flutter Scene build hook into `flutter_scene_generated/`. Those engine-specific outputs are ignored; source assets, generators and dependency resolutions are versioned.

## Validation and recordings

Khronos glTF Validator checks all native GLBs. The full report is [validation/gltf.json](validation/gltf.json). For a reproducible check, install `gltf-validator` outside the game repository and set `SKYWAY_GLTF_VALIDATOR` to its module directory before running `node tool/validate_assets.cjs`.

The native visual-review test writes numbered PNGs to the application container directory printed as `REVIEW_FRAMES`. Encode them with an installed FFmpeg:

```sh
ffmpeg -framerate 12 -i "$REVIEW_FRAMES/before-%04d.png" -c:v libx264 \
  -pix_fmt yuv420p -crf 22 -movflags +faststart docs/recordings/before.mp4
ffmpeg -framerate 12 -i "$REVIEW_FRAMES/after-%04d.png" -c:v libx264 \
  -pix_fmt yuv420p -crf 22 -movflags +faststart docs/recordings/after.mp4
```

The recordings show deterministic review frames, not measured real-time rendering throughput. They have no audio track.
